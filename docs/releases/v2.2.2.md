# AkaTerminal v2.2.2 Release Notes

Installs over v2.2.0 and keeps your data: same signing key, no uninstall needed. (There is no v2.2.1.)

### Terminal and keyboard
- The keyboard now resizes the terminal once each time it opens or closes, instead of on every frame of its animation. Full-screen apps in tmux, such as Codex or Claude Code, no longer creep up the screen and stop filling it after the keyboard has opened and closed a few times.
- When the keyboard opens, the terminal shrinks first and the keyboard slides into the gap. When it closes, the terminal grows back once the keyboard is gone. The keyboard never covers text.
- Pinch zoom and dragging a pop-up window's edges send one size change when you stop, not one per step.

### Terminal font
- Pick your own font: Settings → Terminal → Font → Choose font file. Any monospace `.ttf` or `.otf` works; files that aren't fonts or aren't monospace are refused.
- "Use JetBrains Mono" goes back to the built-in JetBrainsMono Nerd Font, which stays the default.

### Checksums
- SHA-256 for both APKs is listed on the GitHub release page. The debug APK is for diagnosis only: it is signed with a debug key, so it can't update a release install.
